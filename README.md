# 🛡️ Cyber Security Masterclass Notes

Welcome to my comprehensive repository for **Cyber Security**! This repository contains structured study notes, cheat sheets, and practical lab materials covering foundational IT concepts up to advanced threat investigation and security operations.

---

## 📚 Course Modules & Syllabus

| Module No. | Topic Name | Description |
| :---: | :--- | :--- |
| **01** | **Introduction / Lecture 0** | Course overview and foundational cybersecurity roadmap. |
| **02** | **Linux & Python Fundamentals** | Essential Linux commands and Python scripting for security tasks. |
| **03** | **Foundations of Information Security** | Core security principles (CIA Triad, Access Control, Frameworks). |
| **04** | **Application Security & Pentest** | Web app vulnerabilities, OWASP Top 10, and testing methodologies. |
| **05** | **Network Defense & Pentest** | Network protocols, scanning, firewalls, and penetration testing. |
| **06** | **Data Protection & Cryptography** | Encryption algorithms, hashing, public-key infrastructure, and data privacy. |
| **07** | **Governance, Risk & Compliance (ISO, SMS)** | Information security standards, frameworks, risk management, and compliance (ISO/IEC). |
| **08** | **Securing Emerging Technologies** | Security challenges and best practices in cloud, IoT, and modern tech. |
| **09** | **Security Operations Center (SOC)** | SOC overview, analyst roles, alert monitoring, and incident triage. |
| **10** | **SIEM Architecture & Hands-On Splunk** | SIEM fundamentals, log analysis, and hands-on log searching with Splunk. |
| **11** | **RCA & Cyber Breach Investigation** | Root Cause Analysis (RCA), digital forensics, and handling security breaches. |
| **📦** | **Bonus - Job Prep Module** | Interview preparation, resume building, and career guidance in cybersecurity. |
